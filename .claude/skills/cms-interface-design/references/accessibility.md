# Accessibility Checklist

Target WCAG 2.2 AA.
- Semantic landmarks, one meaningful H1, logical heading order.
- Keyboard-operable navigation, tables, editors, menus, dialogs, and drag/reorder alternatives.
- Visible focus indicator; restore focus after dialogs close.
- Text contrast >=4.5:1 (3:1 for large text); UI boundaries and focus >=3:1 where applicable.
- Accessible names for icon buttons, input labels, programmatic errors, and status updates.
- Never communicate statuses or chart meaning by color alone.
- Respect reduced motion, support 200% zoom, and ensure responsive reflow.
- For uploads, provide file selection alternative to drag/drop.
- For data visualization, provide summary or data table where needed.
- Do not rely on hover to reveal critical controls.
